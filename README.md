# WanderMatch

Навчальна вебплатформа для вибору напрямків і планування подорожей.

Сайт: https://wandermatch-lr8.vercel.app/

## Можливості

- Адаптивна навігація та картки напрямків.
- Вибір напрямку з Google Maps, Windy та відеопутівником YouTube.
- Галерея Fancybox і відгуки Swiper з керуванням паузою.
- Форма з клієнтською валідацією та демонстраційним підтвердженням.
- Калькулятор орієнтовного бюджету з перевіркою меж і повним очищенням параметрів.

## Локальний перегляд

Відкрийте папку у VS Code й запустіть index.html через Live Server. Готовий CSS уже включено: Tailwind не компілюється в браузері. Стилі, шрифти та медіабібліотеки збережено локально. Для Google Maps, Windy, YouTube та прев'ю відео потрібен інтернет.

## Розробка та перевірка

Потрібен Node.js 22 або новіший та npm.

```sh
npm ci
npm test
npm run build
```

Tailwind 3.4.17 формує css/tailwind.css із index.html та js/*.js. Збірка копіює сайт у dist. Тести перевіряють ресурси, синтаксис JS, бізнес-формулу, некоректні значення та очищення калькулятора.

## Автоматична публікація

.github/workflows/deploy.yml запускає перевірки й збірку при push або pull request у main. Після успішної перевірки push запускає Vercel CLI: pull, build, deploy --prebuilt --prod. Для pull request деплой пропускається. Для конвеєра налаштовано VERCEL_TOKEN, VERCEL_ORG_ID і VERCEL_PROJECT_ID в GitHub Secrets; значення секретів не зберігаються у файлах.

## Обмеження демонстрації

Тарифи калькулятора навчальні й не є актуальними цінами бронювання. Форма не передає і не зберігає дані. Реальний AI-підбір, особистий кабінет і бронювання залишаються планом розвитку. Перевірка Lighthouse є лабораторним вимірюванням і не замінює тестування на реальних пристроях.
