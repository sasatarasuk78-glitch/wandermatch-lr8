# WanderMatch

WanderMatch — навчальний адаптивний лендинг сервісу персоналізованого вибору подорожей. Сайт знайомить із напрямками та допомагає попередньо дослідити місце перед поїздкою.

**Переглянути сайт:** https://wandermatch-lr8.vercel.app/

## Що реалізовано

- Картки популярних туристичних напрямків та адаптивна навігація.
- Вибір міста з оновленням карти Google Maps, погодного віджета Windy та відеоогляду YouTube.
- Форма зворотного зв'язку з клієнтською перевіркою імені, електронної пошти, українського номера телефону, повідомлення та згоди з політикою конфіденційності.
- Повідомлення про помилки біля полів і модальне вікно після успішної перевірки.
- Макет для комп'ютера та мобільного екрана.

## Технології

HTML5, Tailwind CSS через CDN, власний CSS і JavaScript без фреймворків. Для зовнішнього вмісту використовуються Google Maps, Windy та YouTube.

## Локальний запуск

1. Завантажте репозиторій або виконайте:

   ```bash
   git clone https://github.com/sasatarasuk78-glitch/wandermatch-lr8.git
   ```

2. Відкрийте папку проєкту у VS Code.
3. Запустіть `index.html` через Live Server або відкрийте файл у браузері.

Для завантаження Tailwind CSS, шрифтів, карт, погоди та відео потрібне підключення до інтернету.

## Структура проєкту

```text
index.html             — розмітка сторінки та форми
css/style.css          — додаткові стилі
js/main.js             — інтерактивні елементи лендингу
js/validation.js       — перевірка форми
assets/images/         — зображення та логотип
```

## Поточні обмеження

Форма працює в демонстраційному режимі: дані перевіряються у браузері, але не надсилаються й не зберігаються. AI-підбір, повноцінні VR-тури, особистий кабінет і бронювання належать до подальшого плану розвитку проєкту.
